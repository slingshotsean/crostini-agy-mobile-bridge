# Crostini + Termius + Antigravity Mobile Bridge

Zero-quota, zero-screenshot mobile bridge for ChromeOS Linux (Crostini), Termius SSH, and Google Antigravity 2.0.

## Quick Start
```bash
git clone https://github.com/slingshotsean/crostini-agy-mobile-bridge.git
cd crostini-agy-mobile-bridge && ./install.sh && source ~/.bashrc
```
